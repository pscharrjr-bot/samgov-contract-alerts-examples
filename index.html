Scheduling tip

Save your input as a task, then add a schedule such as 0 7 * * 1-5 (7:00 on weekdays). Set Posted within last N days to 2-3 so weekends are covered. Built-in dedupe means you only get, and only pay for, new notices. Add an email, Slack or Google Sheets integration to the task to receive them. Free SAM.gov keys allow about 10 API calls a day, so keep Max SAM.gov API requests at 1-2.
